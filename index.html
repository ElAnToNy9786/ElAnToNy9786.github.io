Ingeniería & Solución de problemas

Caso de Estudio: Optimización del Sitio

01

Diagnóstico de Dependencias

Detecté y removí enlaces rotos e incompletos de CDNs externas que bloqueaban la carga de Bootstrap 5. Centralicé la lógica de maquetación en código nativo para garantizar que el portafolio funcione de manera independiente y veloz de forma local y en producción.

02

Reestructuración de Multimedia

Diseñé flujos asimétricos con CSS Grid y Flexbox para albergar las diferentes disciplinas del portafolio: un render estático para software, un mosaico dinámico de 4 cuadrantes para arte e ilustración, y una división simétrica al 50% para contenido de producción musical.

03

Interactividad Avanzada Nativa

Implementé un sistema de expansión vertical nativo utilizando etiquetas <details> y transiciones de transformación en CSS. Al hacer clic, la tarjeta de arte se estira orgánicamente hacia abajo y despliega un cortometraje en alta definición (MP4) con miniaturas y controles interactivos sin sobrecargar la página con JavaScript de terceros.

04

Debugging de Rutas Relativas

Resolví conflictos jerárquicos en el árbol de directorios locales. Corregí el direccionamiento de la carpeta de recursos de proyectos a proyects para unificar el enlace entre el HTML raíz y las subcarpetas del servidor.
